# Specs

Antes de implementar uma feature nova, crie primeiro uma spec em `specs/<feature>.md`.

## Regras

- Use nome de arquivo em `kebab-case`.
- Seja específico ao projeto atual.
- Escreva só o necessário para alinhar escopo e abordagem antes da implementação.

## Estrutura mínima

```md
# Título da spec

## Status
- Pesquisa e especificação apenas.
- Nenhuma implementação foi feita nesta tarefa.

## Contexto
- problema
- estado atual
- restrições relevantes

## Objetivo
- resultado esperado

## Não objetivos
- o que fica fora deste corte

## Abordagem proposta
- solução recomendada
- decisões e trade-offs
- impacto nas áreas do projeto, se relevante
```
